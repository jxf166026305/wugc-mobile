# 五层基本面分析 · 手机独立版

**线上地址（已部署）：https://jxf166026305.github.io/wugc-mobile/**

手机打开上面这个地址一次，浏览器菜单里"添加到主屏幕 / 安装应用"，之后点桌面图标直接进。
不需要电脑开机、不需要手机连电脑；壳由 Service Worker 缓存，行情与财报数据直连东方财富。

仓库：https://github.com/jxf166026305/wugc-mobile （公开，只含工具代码，不含个人自选股）

不需要电脑开机、不需要后端服务的版本：所有抓数、评分都在手机浏览器里完成。
数据源仍是东方财富公开数据接口（datacenter-web / push2his）+ 腾讯行情快照。

## 数据源差异（与电脑版不同，必须知道）

电脑版是服务端 PowerShell 抓数，**不受浏览器跨域限制**；手机版是浏览器直连，只能用开放跨域头（`Access-Control-Allow-Origin`）的接口。实测差异：

| 事项 | 电脑版 | 手机版 | 影响 |
|---|---|---|---|
| 7×24 快讯 | 东财 `np-weblist` + 新浪 `zhibo` | 两者都**不带跨域头**，浏览器读不到 | 改用东财"资讯检索"接口按 16 个主题词取稿，实测 229 条、时间到分钟级 |
| 全球指数 | 腾讯 + 新浪 `hq.sinajs.cn` + CNBC + SET 官网 | 统一走东财 `push2` | 恒生科技改用 `124.HSTECH`，俄罗斯 MICEX 换成俄罗斯 RTS（原来那档浏览器取不到） |
| 美股盘前 | 新浪 `gb_*` 带盘前/盘后延时成交 | 腾讯 `us*` 只有常规时段 | **"盘前 / 盘后"两列留空**，不臆造；三大期指里 ES 是真期指，NQ/YM 用东财现货指数补位（名称已标"（现货）"） |
| 个股公告 / 资讯检索 | 同一个接口 | 同一接口（跨域开放） | 无差异 |


## 三种打开方式

**1) 局域网（验证用，电脑需开着）**
电脑运行：`python -m http.server 8080 --bind 0.0.0.0`
手机浏览器：`http://电脑IP:8080/`

**2) 拷到手机（真独立，无安装图标）**
把整个文件夹拷到手机存储，用 Chrome/Edge 打开 `index.html`。
代码已放行 `file://` 模式（不再要求本机服务），但浏览器是否允许 `file://` 页面直连 https 接口，需要真机确认。

**3) 装到桌面（PWA，需要 https）**
把整个目录放到任意 https 静态托管（GitHub Pages / Cloudflare Pages / 对象存储均可），
手机访问一次 → 菜单里"添加到主屏幕" → 之后图标直接打开，壳被 Service Worker 缓存，
即使托管地址失效也能打开（数据仍然需要联网）。

## 已知差异

- `meta.version` 为 `v1.2-mobile`；`meta.cached` 由本地 10 分钟缓存决定。
- PC 版服务端有 10 分钟缓存，手机版同样有，口径一致。
- 手机版没有"服务窗口"，抓数失败时直接在页面上报错。
